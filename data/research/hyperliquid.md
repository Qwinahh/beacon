## Caveats

- **Numbers are intra-day snapshots taken 2026-06-11 and the market was moving fast** (HYPE 24h range $57.17–$65.57). CoinGecko page showed $64.80 while Hyperliquid's own mark price snapshot was $58.65 and a Coinbase-sourced search snippet showed $56.18 — same day, different timestamps. Treat any single price as approximate.
- **OI definitions differ:** the ~$5.88B figure is the sum of openInterest × mark price across the main perp DEX's markets from Hyperliquid's official API (my calculation from raw API data). The ~$2.30B CoinGlass figure is OI on HYPE-the-token futures across exchanges — a different metric. HIP-3 builder-deployed markets (~$3B OI in May per Wu Blockchain) are likely NOT in the main-DEX API sum, so total platform OI is plausibly higher; I could not verify a single combined platform-OI number.
- **Volume discrepancy:** DeFiLlama 24h perp volume ($10.27B) vs official main-DEX API 24h notional (~$5.79B). Likely different 24h windows and/or DeFiLlama including HIP-3/builder markets — unverified, flagged as uncertain.
- **HLP vault TVL (~$335.9M)** comes from DeFiLlama's `hyperliquid-hlp` protocol slug API. I could not cross-check against Hyperliquid's own HLP vault page (POST-only API endpoints for vault details weren't queried). Treat as DeFiLlama's accounting, not necessarily the figure the app UI shows.
- **TVL scope:** $5.88B (DeFiLlama API, protocol slug) vs $6.30B (CoinGecko's displayed DeFiLlama TVL) — likely chain-vs-protocol scope or timestamp difference; unresolved.
- Several June developments (Kalshi filing, ETF launches, lobbying, whale deposit) are sourced from CoinMarketCap's AI-aggregated news page and were not independently confirmed against primary filings/announcements.
- Monthly unlock figures vary by source: ~9.92M HYPE / ~$565M (DEXTools) vs "~238M HYPE monthly vesting" mentioned in another aggregator snippet — the latter is inconsistent with supply math and likely an aggregator error; trust the ~9.92M figure but verify before tweeting.
